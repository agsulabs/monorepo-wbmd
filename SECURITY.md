# Security Policy

## Supported Versions

The project is currently maintained on the `main` branch and through the latest released version.

| Version        | Supported |
| -------------- | --------- |
| latest release | yes       |
| main           | yes       |
| older versions | no        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use one of these channels instead:

- GitHub Security Advisories / private vulnerability reporting, if enabled for this repository
- direct contact with the repository maintainer

When reporting, please include:

- affected package or app
- steps to reproduce
- impact description
- possible fix or mitigation, if known

You will receive an acknowledgement as soon as possible. Valid reports will be investigated and fixed based on severity and impact.

## Scope

Security reports may include issues affecting:

- `apps/backend`
- `apps/web`
- `apps/mobile`
- `apps/desktop`
- `packages/api-client`
- `packages/contracts`
- CI/CD workflows and release process
- dependency and supply-chain risks

## Disclosure Policy

Please allow time for investigation and remediation before any public disclosure.
