# Support

Thanks for using this project.

## Getting Help

For general questions, usage help, or discussion, please use GitHub Issues if an appropriate issue template exists.

Before opening a new issue:

- read `README.md`
- read `CONTRIBUTING.md`
- check the runbooks in `docs/runbooks/`
- search existing issues and pull requests

## What to Include

When asking for help, please include:

- the affected app or package
- what you were trying to do
- what happened instead
- steps to reproduce
- relevant logs, screenshots, or error messages
- your environment details where relevant

## Security Issues

Do not report security vulnerabilities in public issues.

Please follow the instructions in `SECURITY.md`.

## Project Areas

This repository includes:
